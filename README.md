# mi-pd1-uzdevumi

## Apraksts

"Mani uzdevumi" ir vienkāršota ToDo jeb "uzdevumu saraksta" lietotne, kas izveidota ar Claude Opus 5.5 maksas versiju.

## Palaišana

1. Lejupielādē vai klonē repozitoriju: 'git clone https://github.com/andrisb-debug/mi-pd1-uzdevumi'
2. Atver mapi 'mi-pd1-uzdevumi' un ar labo peles taustiņu klikšķinot uz 'index.html' izvēlas 'Open in integrated browser'
3. Serveris nav nepieciešams

## Papildfunkcija

Izvēlēts variants 'A - rediģēšana': dubultklikšķis uz uzdevuma nosaukuma ļauj to mainīt, ENTER saglabā izmaiņas, ESC atceļ izmaiņas.

## Izmantotais MI rīks

Claude Opus 5.5

## Pārbaudes rezultāti

Visas 10 T2 pārbaudes izdevās
